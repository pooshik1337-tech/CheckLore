CheckLore — подробный туториал

Что такое CheckLore

CheckLore — визуальная доска и текстовый редактор, созданный для упрощения работы за компьютером и распределения задач. Вся работа ведётся в одном окне: доска, канбан, календарь, редактор больших текстов, менеджер томов, аналитика.

Все данные хранятся локально на вашем компьютере. Ничего не отправляется в интернет.

Доска

Основное рабочее пространство. Здесь располагаются карточки пяти типов: заметка, абзац, том, картинка и ссылка. Доска — это визуальный навигатор по проекту.

  • ПКМ по пустому месту — открыть меню создания.
  • Двойной клик по карточке — открыть её редактор (тома — в отдельном окне).
  • Перетаскивание — схватил карточку и тянешь. Плавно, без рывков.
  • Ресайз — за правый нижний угол карточки.
  • Shift + клик — добавить карточку в выделение.
  • Ctrl + клик — создать связь с выделенной (якорь).
  • Ctrl + Shift + клик — накидать несколько связей от одного якоря.

Типы карточек

  • Заметка — небольшой текстовый блок. Заголовок, текст, статус, автор, срок, тег, вложения.
  • Абзац — текстовый блок среднего размера (до 1000 символов). Для описания локаций, механик, персонажей.
  • Том — большая статья. Хранится как отдельный файл. Открывается в отдельном окне редактора при двойном клике.
  • Картинка — референс, арт, скриншот.
  • Ссылка — веб-ссылка. Двойной клик открывает браузер.

Зум и панорама

  • Ctrl + колесо мыши — зум вокруг курсора.
  • Средняя кнопка мыши (зажать и тащить) — панорама. Также инструмент H и перетаскивание ЛКМ.
  • Ctrl + 0 — сброс масштаба к 100%.
  • Ctrl + 1 — полный обзор: вся доска помещается на экран.

Режимы просмотра

Три режима переключаются кнопками в топбаре:

  • Доска — визуальный холст со всеми карточками.
  • Канбан — колонки по статусам. Только заметки. Карточку можно перетаскивать между колонками — статус меняется автоматически. Кнопка «+ Карточка» в полосе меню (видна только в канбане).
  • Календарь — неделя или месяц. Показывает карточки с указанным сроком. Стрелки ← → листают, «Сегодня» — прыжок к текущему дню.

Переключить режим календаря (неделя/месяц): клик по стрелочке ▾ рядом с кнопкой «Календарь», ПКМ по кнопке или табам внутри календаря.

Статусы (для канбана)

Стандартные: TODO, В работе, Готово, Отменено. Можно создать свои статусы.

  • В канбане — «+ Добавить статус» в конце списка колонок.
  • ПКМ по шапке кастомной колонки — переименовать, изменить цвет, удалить.
  • Изменение статуса заметки — ПКМ по карточке → «Статус…».

Связи между карточками

  • Ctrl + клик по двум карточкам — создать связь.
  • Повторный Ctrl + клик по связанной — связь удаляется.
  • Клик по линии — предложение удалить связь.
  • ПКМ по карточке → «Отвязать от…» — список всех связей с возможностью удалить по одной или все сразу.

Области

Прямоугольники с названием, которые двигают группу карточек внутри себя. Как папки на доске.

  • R или ПКМ по пустому месту → «Создать область» → протянуть мышью прямоугольник.
  • Двойной клик по шапке — переименовать.
  • Кнопка ▼/▶ — свернуть или развернуть область.
  • ПКМ по шапке — цвет, переименование, удаление.
  • Карточки внутри области едут вместе с ней.

Вложения

К заметке, абзацу или тому можно прикрепить картинки и ссылки.

  • Открой заметку/абзац на редактирование — внизу формы секция «Вложения».
  • «+ Изображение» — открывает проводник, копирует файл в папку workspace.
  • «+ Ссылка» — раскрывает поля URL и Название.
  • Клик по миниатюре или чипу — открывает файл или ссылку.

Прозрачность карточек

  • ПКМ по карточке → «Прозрачность» — ползунок 20–100% только для этой карточки.
  • Настройки → Внешний вид → «Прозрачность карточек» — значение по умолчанию для новых карточек.

Поиск и фильтры

  • Ctrl + F — поиск по доске. Enter — следующее, Shift+Enter — предыдущее, Esc — закрыть.
  • Ctrl + Shift + F — глобальный поиск по всем томам сразу.
  • Y или кнопка «Фильтры» — тип, тег, автор, срок. Не подходящие карточки тускнеют.

Менеджер томов

T в топбаре. Список всех томов: имя, дата, размер, к каким доскам привязан. Можно открыть, переименовать, экспортировать в .md или удалить. Осиротевшие тома подсвечены оранжевым.

Редактор томов

Отдельное окно. Здесь можно писать длинные тексты с форматированием:

  • Шрифты: Segoe UI, Arial, Georgia, Times New Roman, Courier New, Verdana и др.
  • Размеры: от мелкого до заголовка+.
  • Жирный, курсив, подчёркнутый, зачёркнутый.
  • Выравнивание слева / по центру / справа.
  • Списки маркированный и нумерованный.
  • Цвет текста и маркер (жёлтый).

Автосохранение настраивается в Настройках. Ручное — Ctrl+S или кнопка «Сохранить». Экспорт в .md / .txt / .html — кнопка «Экспорт».

Экспорт и импорт

  • E — экспорт всей доски в JSON-файл.
  • PNG — снимок доски в картинку (2× разрешение).
  • В Обзоре досок — «Открыть из…» — импорт доски из JSON.
  • В Менеджере томов — экспорт тома в .md / .txt / .html.

Несколько досок

CheckLore поддерживает несколько досок. D в топбаре открывает обзор всех досок: переключение, создание новой, переименование, удаление, импорт из файла.

Спящие карточки

Если перетащить карточку за пределы доски — она становится полупрозрачной и «спит»: не открывается, не учитывается в аналитике, связи к ней тускнеют. Вернуть: ПКМ по ней → «Вернуть на доску», либо ПКМ по пустому месту доски → «Вернуть все спящие карточки».

Аналитика доски

A в топбаре. Показывает: состав доски по типам карточек, статусы заметок, дедлайны (просрочено / сегодня / эта неделя), топ-5 авторов, топ-5 тегов, количество связей и скрытых.

Настройки

≡ в топбаре или Меню → Файл → Настройки.

  • Цвет линий связи — цвет пунктира между карточками.
  • Прозрачность карточек — по умолчанию для новых.
  • Приветственный экран — что показывать при запуске: меню создания или сразу последнюю доску.
  • Автосохранение томов — от 1 минуты до 3 часов, или «Никогда».

Горячие клавиши — полный список

Откройте окно справки по F1 — там сводная таблица всех сочетаний.

Советы

  • Используйте Области, чтобы группировать карточки по проектам или спринтам.
  • Связи (Ctrl + клик) помогают видеть, что на что влияет.
  • Переключение вида Доска / Канбан / Календарь — разные взгляды на одни и те же данные.
  • Доска — визуальный навигатор. Длинные тексты держите в томах.
