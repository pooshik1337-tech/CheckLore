# CheckLore

Open-source визуальная доска + встроенный текстовый редактор для инди-команд.
Доска — навигатор по проекту: заметки, абзацы, изображения, ссылки и «тома»
(большие текстовые файлы, открываются в отдельном окне CheckLore).

## Возможности

- Доска 1000×1000 (расширяемая по +500 за клик).
- ПКМ по пустому месту: создать заметку / абзац / том / изображение / ссылку.
- ПКМ по элементу: открыть / редактировать / удалить.
- Drag&drop изображений извне прямо на доску.
- Двойной клик по тому — открывается редактор с форматированием
  (шрифты, размер, B/I/U/S, выравнивание, списки, цвет, маркер).
- Две темы: светлая и тёмная.
- Всё хранится локально (board.json + файлы томов + копии изображений).
- Автосохранение.

## Где хранятся данные

`%APPDATA%/CheckLoreWorkspace/` на Windows,
`~/Library/Application Support/CheckLoreWorkspace/` на macOS,
`~/.config/CheckLoreWorkspace/` на Linux.

Внутри:
- `board.json` — доска
- `tomes/tome-<id>.json` — содержимое томов
- `images/img-*` — скопированные изображения

## Запуск

```bash
# 1. установить Node.js 18+ (https://nodejs.org)
# 2. в папке проекта:
npm install
npm start
```

## Сборка в установщик (опционально)

```bash
npm i -D electron-builder
npx electron-builder --dir
```
